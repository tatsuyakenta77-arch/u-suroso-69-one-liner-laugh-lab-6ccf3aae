One short funny line answering the prompt — the excuse a robot vacuum gives after eating a sock:

> The sock attacked first. I have the lint to prove it.

The joke is a deadpan self-defence claim: instead of the obvious "I thought it was a dust bunny", the vacuum blames the victim and offers its own lint as courtroom evidence. It is the vacuum's own voice, it fits the exact situation (a vacuum that just swallowed a sock), and it stays tight at 53 characters — two short sentences, twist first, evidence second, nothing wasted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
